# DEMO / SAMPLE: Startup problems and boot failure

Category: startup

Record startup error messages. Disconnect nonessential peripherals and check power. Avoid repeated forced shutdowns. Do not reset, reimage, change boot security or erase disks without IT approval and verified backups. Recovery-key requests, boot loops and suspected data loss require IT support.
