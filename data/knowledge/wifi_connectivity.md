# DEMO / SAMPLE: Wi-Fi weak signal and disconnects

Category: wifi_connectivity

Weak Wi-Fi signal can cause intermittent connectivity. Move closer to the approved access point, verify airplane mode and reconnect to the approved network. Compare another device on the same network. Do not disable enterprise security controls. Ask IT about persistent access-point or authentication problems.
