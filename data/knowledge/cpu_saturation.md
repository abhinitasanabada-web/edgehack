# DEMO / SAMPLE: CPU saturation and slow laptop

Category: cpu_saturation

Sustained high CPU can slow a PC. Check Task Manager or Activity Monitor and identify the busiest process. Save work and close an unneeded application normally. Check for approved updates. Do not terminate unknown system processes. Escalate persistent unexplained CPU load to IT.

Source: synthetic hackathon knowledge, not official HP guidance. Thresholds are illustrative and require fleet-specific validation.
