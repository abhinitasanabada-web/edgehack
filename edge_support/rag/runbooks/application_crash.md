# Application crash

## Symptoms
An application closes unexpectedly or becomes unresponsive.

## Evidence to collect
Application name, recent errors, process state, and reproduction steps.

## Likely causes
Application defect, corrupted state, memory pressure, or incompatible update.

## Approved fixes
No automatic application reinstall or data deletion.

## Verification steps
Reproduce the problem and confirm the application remains responsive.

## When to escalate
Escalate when crash evidence implicates data loss, drivers, or an unknown binary.
