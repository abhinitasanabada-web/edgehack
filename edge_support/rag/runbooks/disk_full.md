# Disk full

## Symptoms
Applications cannot save files or updates fail.

## Evidence to collect
Drive free space, approved temporary workspace size, and recent errors.

## Likely causes
Temporary files, large user data, logs, or an incomplete update.

## Safe diagnostic commands
Inspect sizes without deleting user files.

## Approved fixes
Clear only the EdgeSupport-approved temporary workspace after confirmation.

## Verification steps
Recheck free space and confirm the approved workspace shrank.

## When to escalate
Escalate before deleting user files or changing partitions.
