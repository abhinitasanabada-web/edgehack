# Suspicious process

## Symptoms
An unknown process uses resources or triggers a security alert.

## Evidence to collect
Publisher, path category, signature status, parent process, and alert metadata.

## Likely causes
Legitimate software, unwanted software, or compromise.

## Approved fixes
No automatic termination of unknown processes.

## Verification steps
Security tooling must confirm the process disposition.

## When to escalate
Always escalate suspected security incidents.
